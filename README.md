# Koyanagi

A minimalist and sober grayscale theme for Omarchy.

## Installation

```bash
omarchy theme install https://github.com/YutaKoyanagi10/omarchy-koyanagi-theme.git
```

## Full Configuration

For the complete koyanagi look (gaps, borders, blur, opacity), see [koyanagi-config](https://github.com/YutaKoyanagi10/koyanagi-config).
